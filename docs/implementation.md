# 首版实施与验收

范围与口径见 [design.md](design.md)，进度仅见 [../NEXT.md](../NEXT.md)。

1. 查询基础：三种适配器、校验、精确金额、SQLite。出口：单位/无限/业务失败/格式异常测试通过。
2. 管理闭环：供应商、Key、批量导入、任务与历史、响应式前端。出口：添加、刷新、失败保留旧值、编辑切分历史可验证。
3. 巡检通知：并发合并、重启恢复、状态提醒、日报、保留期限。出口：同 Key 合并、限流处理、通知去重与恢复测试。
4. Bot 与部署：共享命令、Telegram polling、OneBot WS、SnowLuma Compose 集成与站内 QQ 管理。先验证统一认证与管理员密码轮换、显式协议确认、外部驱动认证/改密、配置保留与脱敏、备份重加密、后端 VNC 认证和无密码浏览器桌面、原始端口未发布及 Compose 配置；最终出口是经授权的真实 QQ 登录、命令收发和 TG 提醒。
5. 收尾：类型检查、构建、浏览器交互、备份恢复、使用文档；GitHub push 后检查与多架构镜像发布，以及仅凭 Compose / .env 的服务器部署。出口：按 README 完成启动和管理闭环，实际浏览器检查通过；真实供应商抽样核对须另行授权。

源码完成和验收完成分别记录在 NEXT。实现代码不等于真实供应商/QQ/TG 联调通过；未取得接入条件的验收保持未完成。依赖安装、外部账号使用、镜像拉取不由设计批准自动授权。
